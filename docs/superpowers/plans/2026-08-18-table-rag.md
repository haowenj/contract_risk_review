# Table RAG Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 为合同 RAG 增加 table 的 searchable_text、retrieval_context、向量化、召回和 Evidence 支持，同时保持现有 text Node 行为不变。

**Architecture:** 使用 Python 标准库 `html.parser.HTMLParser` 将每张 MinerU table 展开成稳定的行列文本。table 作为单独的 TextNode 进入现有 RAG 流程，原始 table_body 和定位 metadata 保存在 Node metadata 中并在最终 Evidence 中返回。

**Tech Stack:** Python 3、`html.parser.HTMLParser`、LlamaIndex `TextNode`、现有 retrieval_context 和 RAG Pipeline。

**Spec:** `docs/superpowers/specs/2026-08-18-table-rag-design.md`

## Global Constraints

- 不修改现有 text Node 行为。
- 一张 MinerU table 第一版只生成一个 Node。
- HTML 到 searchable_text 必须使用纯代码完成，不新增 BeautifulSoup/lxml。
- `table_caption`、`table_footnote` 必须同时进入 searchable_text 和 table retrieval_context 输入。
- table metadata 必须保留 `source_object_index`、`page_idx`、`bbox`、`table_body`，并增加 `node_type=table`。
- table 的 embedding 内容使用 `searchable_text + retrieval_context`。
- 原始 table 信息必须可序列化到最终 Evidence。
- 暂不处理跨页 table 和超大 table 拆分。

- [ ] **Step 3: Implement the minimal parser**

Use `HTMLParser` with a small row/cell state machine:

```python
class _TableParser(HTMLParser):
    def __init__(self):
        super().__init__(convert_charrefs=True)
        self.rows = []
        self.current_row = None
        self.current_cell = None

    def handle_starttag(self, tag, attrs):
        if tag == "tr":
            self.current_row = []
        elif tag in {"td", "th"}:
            self.current_cell = []
        elif tag == "br" and self.current_cell is not None:
            self.current_cell.append(" ")

    def handle_endtag(self, tag):
        if tag in {"td", "th"} and self.current_cell is not None:
            cell_text = " ".join("".join(self.current_cell).split())
            if self.current_row is not None:
                self.current_row.append(cell_text)
            self.current_cell = None
        elif tag == "tr" and self.current_row is not None:
            self.rows.append(self.current_row)
            self.current_row = None

    def handle_data(self, data):
        if self.current_cell is not None:
            self.current_cell.append(data)
```

Normalize whitespace in each cell, join cells with ` | `, join rows with newline, and prefix caption/footnote fields. Do not interpret or duplicate `rowspan`/`colspan` values.
